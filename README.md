# 🎭 DeepFake Detection Web Application

An AI-powered web application that detects whether an uploaded image or video is **REAL or FAKE** using deep learning.

## 🚀 Features

- 🖼️ Upload images for DeepFake detection
- 🎥 Upload videos for DeepFake detection
- 🤖 Xception-based deep learning model for image analysis
- 🔍 Frame-based analysis for videos
- 📊 Displays REAL / FAKE prediction with confidence
- 🌐 Simple and user-friendly web interface
- ⚡ Flask-based backend

## 🧠 Technologies Used

- Python
- Flask
- TensorFlow / Keras
- Xception CNN
- OpenCV
- NumPy
- Pillow
- HTML
- CSS
- JavaScript
